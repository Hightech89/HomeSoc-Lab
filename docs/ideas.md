# Home SOC Idea Backlog

This document exists to capture good ideas without distracting from the current roadmap.

## Current Rule

Before starting any new feature, ask:

1. Does this improve **my** Home SOC?
2. Am I solving a problem I actually have today?
3. Can this wait until after the current roadmap?

If it can wait, it belongs in this file.

## Future SaaS Idea

**Status:** Someday (Not Now)

Allow other users to connect and manage their own Home SOC labs.

Requirements before considering:

- Build and use my own portal daily.
- Validate that it solves my own problem.
- Do not build multi-user features until the single-user experience is mature.
